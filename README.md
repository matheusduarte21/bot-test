# 🕷️ Portal da Transparência Crawler

Este projeto é um crawler desenvolvido com **NestJS** e **Puppeteer** para buscar dados de servidores públicos no [Portal da Transparência](https://portaldatransparencia.gov.br/). Ele acessa a plataforma, pesquisa por CPF e extrai o histórico de vínculos públicos da pessoa consultada.

## 🚀 Tecnologias utilizadas

- [NestJS](https://nestjs.com/)
- [Puppeteer](https://pptr.dev/)
- [Node.js](https://nodejs.org/)
- [TypeScript](https://www.typescriptlang.org/)
